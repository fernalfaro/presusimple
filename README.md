# PresuSimple

Generador web de presupuestos pensado para profesionales independientes y pequeños negocios.

## Funciones

- Cálculos automáticos de subtotal, descuento, impuestos y total.
- Servicios editables y eliminables.
- Vista previa del documento en tiempo real.
- Persistencia local de la información.
- Impresión y exportación mediante PDF.
- Diseño adaptable a escritorio y dispositivos móviles.

Proyecto demostrativo creado con HTML, CSS y JavaScript.
